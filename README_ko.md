# 원격돌격 v1.5 업데이트

## 반영 내용
- 메인 화면의 큰 소개 배너를 제거하고 그 자리에 상점과 우편함 배치
- 메뉴의 메일 이름을 우편함으로 변경
- 250 / 300 / 400 / 500 트로피 달성 시 각각 원코인 500개 지급 (계정별 1회)
- 캐릭터별 공격·궁극기 효과음 추가 (Web Audio 합성음, 외부 파일 불필요)
- 유르 체력 100 → 85
- 메토 기본 공격 피해 5 → 7
- 아담 체력 100 → 80, 궁극기 자동 충전 초당 4%, 기본 공격 적중당 15%
- 아담 공격을 앞으로 뻗는 연속 잽 모션으로 변경

## GitHub / Render 반영 방법
1. ZIP 압축을 풉니다.
2. 기존 GitHub 저장소의 루트에 `index.html`, `package.json`, `server.js`를 올리고 같은 이름 파일을 덮어씁니다.
3. GitHub에 커밋/푸시하면 Render가 자동 배포하도록 설정된 경우 새 버전이 배포됩니다. 자동 배포가 꺼져 있으면 Render 대시보드에서 수동 배포를 실행하세요.
4. 배포 후 브라우저에서 새로고침하고 다시 로그인해 확인하세요.

## 참고
- 이번 게임 변경의 대부분은 `index.html`에 있습니다. `server.js`는 이전 온라인 서버 버전을 그대로 포함했습니다.
- 기존 브라우저 계정은 같은 브라우저의 localStorage에 남아 있습니다. 이전에 트로피 250개와 300개를 넘겼지만 해당 보상을 아직 받은 적 없는 계정은 로그인 시 각각 500 원코인씩 소급 지급되며, 중복 지급되지 않도록 기록됩니다.
- Render의 기존 환경 변수와 PostgreSQL 설정은 유지하세요.
