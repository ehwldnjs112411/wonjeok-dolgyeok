# 원격돌격 v2.1 업데이트

## 파일
- `index.html`: 게임 클라이언트
- `server.js`: 온라인 매칭과 상태/피해 중계
- `package.json`: Node.js 실행 설정

## 적용 방법
1. GitHub 저장소 루트에서 위 3개 파일을 교체합니다.
2. 기존 Render 환경 변수(`DATABASE_URL`, `JWT_SECRET`)는 유지합니다.
3. GitHub에 커밋/푸시한 뒤 Render 배포 로그에서 배포 성공을 확인합니다.
4. 게임은 `Ctrl+F5`로 새로고침합니다.

## 업데이트 요약
- 전투 정보 오른쪽 패널은 궁극기 충전 바/포인트만 표시합니다.
- 온라인 플레이어는 좌우 시작 위치를 고정하고 원격 상태를 부드럽게 보간합니다. 서버는 0 피해 기절/매혹 상태도 상대에게 전달합니다.
- 조키 기절 궁극기는 더 선명한 시각 효과로 표시됩니다.
- 51~100층의 AI/보스 스킬, 보상, 음악 선택 및 100층 연출을 정리했습니다.
- 구미(상점 1500 코인), 할로윈 우편함(트로피 +100, 계정당 1회)을 포함합니다.

참고: YouTube 링크는 브라우저/영상별 임베드 및 자동 재생 제한을 받을 수 있습니다. `youtube.com/results` 검색 URL 자체는 직접 재생 가능한 오디오 파일이 아니므로, 피격 소리는 게임 내 합성 효과음을 사용합니다.
