# 원격돌격 v1.9 업데이트

## 적용 방법
1. 압축을 풉니다.
2. 기존 GitHub 저장소 루트의 `index.html`, `server.js`, `package.json`을 이 폴더의 파일로 교체합니다.
3. 커밋 후 GitHub에 푸시합니다. Render 자동 배포가 설정되어 있으면 새 버전이 배포됩니다.
4. 기존 Render 환경 변수와 데이터베이스 설정은 유지하세요.

## 주요 변경
- 조키는 상점에서 1500 원코인으로 구매하도록 변경
- 아담: 일반 공격 적중 궁 충전 7%, 궁극기 3초 동안 적중 회복량 4, 궁 상태 중 충전 정지
- 뿌지직 기본 공격 속도 상향
- 탑 모드 50층까지 확장, 10/20/30/40/50층 보스전
- 보스 7초마다 12발 원형 탄막을 3회 발사, 50층 보스는 13초마다 피해 11의 대형 탄환 발사
- 21~40층 AI는 5초마다 체력 4 회복, 41층부터 AI 두 명(각 체력 50)
- 보스전 시작 시 1초간 '보스전!!' 후 3-2-1 카운트다운
- YouTube 음악을 메뉴/일반 전투/탑 전투/보스전에 맞춰 전환하고 곡 종료 시 반복

## 음악 참고
음악은 제공된 YouTube 영상 ID를 임베드해 재생합니다. 자동 재생은 브라우저의 사용자 상호작용 정책 및 YouTube 영상의 임베드 가능 여부에 따라 제한될 수 있습니다.
