# 원격돌격 v2.1.3 — 원 도감 화면 복구

## 수정 사항
- 원 도감 버튼을 눌렀을 때 `renderCollection()`을 실행하도록 수정했습니다.
- 이제 현재 계정의 캐릭터 카드, 설명, 체력/속도/궁극기 정보, 선택 버튼이 화면에 표시됩니다.

## 적용 방법
1. GitHub 저장소 루트의 기존 `index.html`을 이 폴더의 `index.html`로 교체합니다.
2. `server.js`와 `package.json`은 변경하지 않습니다.
3. 변경 사항을 커밋하고 푸시한 뒤 Render 배포를 기다립니다.
4. 웹사이트에서 Ctrl+F5로 강력 새로고침 후 원 도감을 엽니다.

JavaScript 문법 검사 통과. 실제 Render 배포 환경의 브라우저 테스트는 수행하지 않았습니다.
