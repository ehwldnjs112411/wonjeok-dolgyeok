# 원격돌격 캐릭터 외형 업데이트

- 뿌지직: 똥을 모티브로 한 갈색 말림 실루엣과 표정, 공격 시 점액/가스 잔상. 메뉴·도감·상점·전투 외형 적용.
- 메토: 군모, 군복, 계급 배지, 소총을 메뉴·도감·상점·전투 외형에 적용.
- 캐릭터 능력치, 공격/궁극기 로직 및 서버 로직은 변경하지 않았습니다.

## 배포
기존 프로젝트의 `index.html`을 교체하세요. `server.js`와 `package.json`은 직전 전체 프로젝트 파일을 그대로 포함합니다.

## 검사
인라인 JavaScript 구문 검사와 ZIP 무결성 검사를 통과했습니다. 실제 브라우저/온라인 2인 전투 검증은 수행하지 못했습니다.
