# 원격돌격 업데이트

## 이번 업데이트
- 엘리의 선택 전사 메뉴 초상화 크기 누락 수정
- SELECTED FIGHTER 카드를 클릭하면 원 도감으로 이동
- 메뉴 상단의 할로윈 이벤트 버튼을 제거하고 기존 원 도감 타일 위치에 이벤트 타일 배치
- 피격 시 붉은 파편 수·크기·비산 거리·잔상 링을 강화 (게임 피해량에는 영향 없음)

## 배포
기존 GitHub 프로젝트에서 `index.html`을 교체해 주세요. `server.js`와 `package.json`은 이전 업데이트 파일을 그대로 포함했으며, 이번 수정에서는 서버 코드를 변경하지 않았습니다.

## 확인
- 인라인 JavaScript 구문 검사 수행
- 메뉴 HTML의 버튼 ID와 이벤트 연결 확인
- 실제 브라우저 렌더링 및 2인 온라인 대전은 이 실행 환경에서 자동 재현하지 못했습니다.
