# 원격돌격 v1.7 업데이트

## 적용된 변경사항
- 배경음악 컨트롤을 메뉴 화면 안에 작게 통합하고, YouTube 영상 화면은 보이지 않게 처리했습니다. 음악 켜기/끄기 버튼을 제공합니다.
- 메뉴 음악은 `nRrXhgEqJMI`이며 전투 종료 또는 메뉴 복귀 시 메뉴 음악으로 전환합니다.
- 일반 AI/유저 매칭은 지정한 전투 트랙에서 무작위 재생합니다.
- 탑 모드는 일반 층에 지정된 3곡을 무작위 재생하고, 10/20/30층 보스는 `wbO3p7_Mf30`, 40층 보스는 `KK3KXAECte4`를 재생합니다.
- 조키 기본 사탕 피해 3, 강화 궁극기 중 피해 5로 변경했습니다.
- 조키는 상점에서 1500 원코인으로 구매할 수 있습니다.
- AI가 벽과 모서리에 몰렸을 때 옆으로 빠져나오도록 벽 회피 조향을 추가했습니다.
- 탑 AI 체력은 각 10층 구간에서 기본 100부터 층마다 10씩 증가합니다. 10/20/30/40층 보스 체력은 각각 250/300/350/500이며 보스 층은 보스 1명입니다.
- 10/20/30/40층은 보스전으로 표시됩니다.

## 배포
기존 GitHub 저장소 루트의 `index.html`, `server.js`, `package.json`을 파일 묶음에 포함된 것으로 교체하고 커밋/푸시하세요. Render의 기존 환경 변수는 유지하세요.

YouTube 임베드 자동재생은 브라우저 정책 및 영상 소유자의 임베드 설정에 따라 제한될 수 있습니다. 음악이 시작되지 않으면 메뉴의 음악 켜기 버튼을 눌러 주세요.
