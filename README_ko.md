# 원격돌격 할로윈 업데이트 v2.2.0

## 변경 사항
- 메뉴 배경 음악을 YouTube 영상 `DtJ6Q_m8kVg`로 변경
- 메뉴에 할로윈 이벤트 버튼 및 좌측 보스전 / 우측 미션 화면 추가
- 할로윈 보스전 1회 승리: 사탕 2개
- 일반 AI 매칭 3회 승리: 사탕 1개
- 탑 모드 10층 클리어: 사탕 2개 (기존에 10층 이상 클리어한 계정도 자동 반영)
- 사탕 5개 수집 시 할로윈 한정 전사 킁킁 지급
- 킁킁: 체력 95, 재장전 1.9초, 속도 490 / 피해 7 호박 투척, 5회 적중 궁극기(4개 표창 3초 회전 후 중거리 유도 발사)
- 보스 충전 카운터 확대, 충전탄 파란색 및 발사 임팩트 추가
- 보스 창 스킬 쿨타임 22초, 찌르기 후 회수 모션 추가
- 일반 보스 보라색, 100층 보스 검정·빨강 색상
- 구미 매혹 적중 시 체력 9 회복, 온라인에서도 피해 0 상태 효과가 전달되도록 서버 수정
- 뿌지직 7발 공격을 45도 불규칙 산탄으로 변경

## GitHub / Render 적용
ZIP 안의 `index.html`, `server.js`, `package.json`을 저장소 루트에서 교체하고 커밋/푸시합니다. Render 자동 배포가 끝나면 브라우저에서 Ctrl+F5로 새로고침하세요.

## 주의
YouTube 배경 음악은 IFrame Player로 재생합니다. 브라우저의 자동 재생 정책에 따라 첫 클릭 후 재생이 시작될 수 있습니다. 코드 문법과 ZIP 무결성 검사는 제작 환경에서 수행했지만, 실제 Render 배포 / 두 계정의 온라인 대전 / 전체 이벤트 플레이는 여기서 실행 검증하지 않았습니다.
