# 원격돌격 v2.1.1 로그인 수정

## 수정 내용
- 빠져 있던 `loginUser()` 함수를 복구해 로그인/회원가입 후 메뉴 화면으로 이동하도록 수정
- 계정 프로필 저장 및 메뉴 정보 갱신 함수 복구
- 트로피 원코인 보상 처리 함수 복구
- 로그인 처리 중 오류가 발생하면 입력창 아래에 안내 문구를 표시

## 적용 방법
1. 기존 저장소의 루트에서 `index.html`, `server.js`, `package.json`을 교체합니다.
2. GitHub에 커밋/푸시하고 Render 배포 완료를 기다립니다.
3. 사이트에서 Ctrl+F5로 강력 새로고침합니다.

참고: 현재 로그인 계정은 브라우저의 localStorage에 저장되는 구조입니다. 다른 기기 간 계정 공유는 서버 인증 기능을 별도로 연결해야 합니다.
