# 원격돌격 v1.8 업데이트

## 이번 수정
- AI 매칭 모드 선택 화면의 누락된 CSS를 복구해 어두운 카드 UI, 반응형 그리드, 패딩을 정상화.
- 조키의 `joki-orb` 캐릭터 아트 스타일을 추가.
- 메뉴 음악은 전투 시작 시 재생 위치를 저장하고, 전투 종료 후 해당 위치부터 이어 재생.
- YouTube 음악 플레이어 API를 사용해 트랙 종료 시 자동 반복.
- 음악 켜기/끄기 유지, 플레이어 오류 시 상태 메시지 표시.
- Socket.IO 클라이언트를 서버의 `/socket.io/socket.io.js`에서 불러오고 온라인 대기열/매칭 이벤트를 연결.
- 탑 모드 AI 체력: 1~9층 100, 11~19층 100, 21~29층 및 31~39층 50.
- 보스 체력: 10층 130, 20층 140, 30층 150, 40층 160. 보스 층은 보스 한 명만 등장.

## Render 배포
1. `index.html`, `server.js`, `package.json`을 기존 저장소 루트에 반영합니다.
2. GitHub에 커밋/푸시하고 Render 배포가 완료될 때까지 기다립니다.
3. Render 서비스의 Start Command가 `npm start`인지 확인합니다.
4. 유저 매칭은 Node 웹 서비스에서 동작해야 합니다. 정적 사이트로 배포하면 Socket.IO 연결을 사용할 수 없습니다.
5. Render 로그에서 `원격돌격 서버가 ... 포트에서 실행 중입니다.`를 확인합니다.

## 참고
- 음악 재생은 브라우저 자동재생 정책과 YouTube 영상의 임베드 허용 설정에 영향을 받습니다. 일부 기기에서는 첫 사용자 클릭으로 재생 권한을 허용해야 합니다.
- 실제 Render 배포 및 실기기별 음악 재생은 이 파일 생성 환경에서 직접 확인할 수 없습니다.
