# 원격돌격 v1.6 업데이트

## 이번 업데이트

### 메인 메뉴와 음악
- 게임 메뉴에서 AI 매칭을 누르면 `AI 기본`과 `탑 모드`를 선택할 수 있습니다.
- 로그인/메뉴에서는 지정된 YouTube 영상(`nRrXhgEqJMI`)을 재생하고, 전투에 들어가면 요청한 6개 영상 중 하나를 무작위로 선택해 재생합니다.
- 음악은 YouTube 임베드 플레이어로 재생합니다. 브라우저 자동재생 정책이나 영상의 임베드 제한으로 자동 재생되지 않을 때는 플레이어에서 재생을 눌러 주세요. 외부 음원을 다운로드하거나 게임 파일에 직접 복제하지 않습니다.

### 캐릭터 변경
- 스파이더맨의 표시 이름을 **스피디**로 변경했습니다(기존 캐릭터 ID/계정 선택은 유지).
- **망치보이** 기본 체력: 105 → 110.
- **뿌지직** 기본 공격 재장전/발사 간격을 줄여 공격 속도를 높였습니다.
- **아담** 체력은 80을 유지합니다. 기본 공격 적중당 궁극기 충전은 5%이며, 궁극기 사용 시 3초 동안 무적이 되지 않고 적중 회복량이 2에서 4로 증가합니다. 해당 3초 동안은 궁극기가 충전되지 않고, 종료 후 회복량이 2로 돌아오며 충전이 재개됩니다.
- **조키**를 추가했습니다(체력 95, 기본 공격 재장전 1.7초). 사탕을 공격 순서에 따라 1개, 2개, 3개, 4개 던진 후 반복하며 사탕 하나당 피해는 4입니다. 궁극기는 충전 중에는 종류를 숨기고, 완전히 충전되면 현재 궁극기를 표시합니다. 사용하면 새 궁극기를 무작위로 뽑습니다.
  - 회복 궁극기: 8초 동안 초당 체력 2 회복.
  - 피해 궁극기: 3초 동안 사탕 하나당 피해를 4에서 6으로 증가.
  - 기절 궁극기: 매우 짧은 거리에서 적중하면 1초 기절.

### 탑 모드
- 총 40층이며, 진행 상황과 각 층의 첫 승리 보상은 계정에 저장됩니다.
- 1~10층: AI 한 명, 난이도 1단계에서 10단계로 상승.
- 11~20층: AI 한 명, 층별 난이도가 다시 1~10단계로 상승하며 공격 피해는 10.
- 21~30층: AI 두 명. 첫 번째 AI의 난이도는 층마다 상승하고 두 번째 AI는 기본 난이도입니다.
- 31~40층: AI 두 명의 난이도가 1~10단계로 함께 상승하며 공격 피해는 각각 9.
- 1~9, 11~19, 21~29, 31~39층 첫 승리: 층마다 원코인 100개.
- 10층, 20층, 30층 첫 승리: 층마다 원코인 500개.
- 40층 첫 승리: 원코인 1,000개와 `축하합니다. 모든 층을 이겼습니다.` 메시지.
- 이미 받은 층 보상은 다시 지급하지 않습니다. 패배하면 같은 층을 다시 도전할 수 있습니다.

### 기존 v1.5 변경도 유지
- 메뉴의 큰 소개 배너를 제거하고 상점·우편함 중심으로 배치, 메일 이름을 우편함으로 변경.

## GitHub / Render 배포
1. ZIP 압축을 풉니다.
2. 기존 GitHub 저장소 루트에 `index.html`, `server.js`, `package.json`을 같은 이름으로 덮어씁니다. `README_ko.md`도 올려도 됩니다.
3. GitHub에 커밋/푸시합니다. Render 자동 배포가 켜져 있으면 새 버전이 배포되며, 꺼져 있으면 Render 대시보드에서 수동 배포를 실행하세요.
4. 기존 Render 환경 변수와 PostgreSQL 설정은 유지하세요.
5. 배포 후 강력 새로고침 후 로그인하여 메뉴, 캐릭터 선택, AI 기본, 탑 모드, 보상 및 음악을 확인하세요.

## 참고
- 파일을 준비하고 JavaScript 문법 및 브라우저 내 주요 기능 스모크 테스트를 실행했습니다. 여기서 GitHub/Render에 직접 업로드하거나 실제 온라인 서버에 배포한 것은 아닙니다.
- YouTube 플레이어는 브라우저 정책과 영상 소유자의 임베드 설정을 따릅니다. 자동재생이 제한되면 직접 재생 버튼을 눌러야 할 수 있습니다.
- 기존 계정/DB는 유지되도록 구성되어 있습니다. 새 캐릭터 조키는 계정의 잠금 해제 목록에 추가되며, 탑 진행과 첫 승리 보상 기록은 저장됩니다.
