# 원격돌격 — 비트 업데이트

## 이번 업데이트
- 비트 신규 전사 추가: 체력 85, 재장전 1.7초, 메토와 같은 발사 간격
- 비트 저격탄: 전장 이동 거리 비례 2~16 피해, 적중 시 5~40% 궁극기 충전
- 비트 궁극기: 자신 주변 360도 반경 230 폭탄 설치, 1초 후 9 피해와 넉백
- 비트 상점 등록: 1,500 원코인
- 트로피 보상 추가: 600/700/800/900/950에서 각 500 코인, 1000에서 1000 코인
- 메뉴 배치: 위쪽 큰 카드 유저 매칭·상점, 음악 오른쪽 위 할로윈 이벤트, 아래쪽 AI 매칭·우편함·원 트로피
- 온라인 투사체 충돌은 발사자 측의 보간된 상대 위치가 아니라 수신자 측의 실제 자기 캐릭터 위치에서 판정
- 온라인 비트 폭탄과 거리 비례 저격탄, 저격탄 충전 반환 이벤트 추가
- 모바일 터치 조준 방향 유지 및 터치 기기의 합성 마우스 이동으로 인한 방향 덮어쓰기 방지
