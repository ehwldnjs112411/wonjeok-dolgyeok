# 원격돌격 · 좀비모드 렌더링 & 볼트 조준 최종 수정

## 이번 수정 범위
- 좀비모드의 빈 전장을 만들던 카메라 함수 스코프 오류를 수정했습니다. 전투 렌더러가 접근하도록 카메라 계산 함수를 `window`에 연결했습니다.
- 좀비모드 시작 시 플레이어를 기존 시야 중앙에 배치하고, 화면 크기는 그대로 둔 채 확대된 전장을 따라 카메라가 이동하도록 유지했습니다.
- 볼트 모바일 일반 공격을 엘리 궁극기와 동일한 누르기-드래그-놓기 조준 방식으로 맞췄습니다. 이동 중 조준점이 실시간으로 따라오며, 사거리 원과 낙하지점 표시를 유지합니다.
- 볼트 기본 공격 사거리를 직전 배포본보다 1.4배 확장했습니다.
- 메뉴 음악, 게임의 다른 전투원과 기존 모드 동작은 변경하지 않았습니다.

## 배포
압축을 푼 뒤 GitHub 저장소 최상위 폴더의 `index.html`, `server.js`, `package.json`, `README.md`를 교체하고 커밋/푸시하세요. 실제 게임 코드 변경은 `index.html`에만 있으며 서버와 패키지 설정은 직전 배포본을 유지했습니다.

## 검사
- 인라인 JavaScript 개별 및 전체 결합 구문 검사 통과
- 좀비 모드 전투 업데이트 함수 패치 구문 검사 통과
- 좀비 모드 버튼, 캔버스, 모바일 공격 버튼 연결 검사 통과
- 카메라 함수의 전역 접근 및 볼트 드래그 중 실시간 조준 이벤트 연결 확인
- ZIP 무결성 검사 완료

실제 브라우저에서 플레이하는 수동 테스트는 이 환경에서 완료하지 못했습니다.
