# 원격돌격 · 좀비모드 버프 카드 & 볼트 모바일 자동 조준 업데이트

## 반영 내용
- 볼트 모바일 일반 공격을 공격 버튼을 누르는 즉시 가까운 살아 있는 적에게 자동 조준해 발사하도록 변경했습니다. 드래그 조준은 제거했습니다.
- 볼트 탄창을 3발로 고정하고, 재장전 간격은 2초로 유지하면서 연속 발사 간격을 짧게 조정했습니다.
- 볼트 기본 공격 사거리를 엘리 궁극기 범위의 정확히 1.4배로 설정했습니다.
- 좀비모드에서 화면 밖 좀비 방향 화살표, 맵 중앙 스폰을 유지했습니다.
- 5웨이브마다 아직 획득하지 않은 카드 중 2장을 제시하고 1장을 선택하도록 했습니다. 11종 카드의 효과와 중복 방지, 전부 획득한 뒤 카드 선택 종료를 적용했습니다.
- 10웨이브를 클리어할 때마다 다음 웨이브부터 좀비 공격력이 10%씩 증가합니다.
- 좀비모드 전용 음악을 지정한 트랙(uA6mBZRrMjA)으로 설정했습니다. 메뉴 음악 동작은 유지했습니다.
