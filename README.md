# 원격돌격 · 티모 & 원 도감 개편 업데이트

## 적용 내용
- 원 도감 카드에서 캐릭터 설명 문장과 체력/이동속도/궁극기/재장전 정보 배지를 제거했습니다.
- 각 전사의 `전사 선택` 옆에 `상세설명` 버튼을 추가했습니다. 버튼을 누르면 체력, 재장전, 기본 공격, 궁극기, 캐릭터 설명을 간단한 팝업으로 확인할 수 있습니다.
- 신규 일반 전사 티모를 추가했습니다. 체력 75, 원거리 가시 공격(피해 2, 재장전 2.1초), 적중 시 4초 중독(초당 1 피해).
- 티모 궁극기는 주변 360도에 버섯 3개를 설치합니다. 버섯은 15초 동안 유지되며 적이 밟으면 사라지고 10초 중독(초당 1 피해)을 부여합니다.
- 티모를 상점에 추가했습니다. 가격은 1,500 원코인입니다.
- 티모의 중독 투사체 및 버섯 함정 이벤트를 유저 매칭 동기화 메시지에 포함했습니다.

## 배포 방법
압축을 푼 뒤 GitHub 저장소 최상위 폴더의 `index.html`, `server.js`, `package.json`, `README.md`를 교체하고 커밋/푸시하세요. Render는 기존 설정대로 자동 배포됩니다.

## 검사
인라인 JavaScript와 `server.js` 문법 검사, ZIP 무결성 검사를 수행했습니다. 실제 온라인 2인 대전은 별도 플레이 테스트가 필요합니다.
