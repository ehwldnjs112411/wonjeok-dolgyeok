# 원격돌격 비트 리모델링 업데이트

- 비트의 전투 외형을 메토의 올리브 군모 형태에서 구분되는 남색 후드·전술복·장거리 저격총 디자인으로 변경했습니다.
- 비트의 원 도감 프로필을 기본 전사 카드 형식으로 되돌렸습니다.
- 비트의 한정판 테두리, 리본, 별도 상세 설명 패널을 제거했습니다.
- 비트는 계속 일반 전사이며 상점에서 1,500 원코인으로 구매합니다.
- 체력, 이동 속도, 공격 피해, 재장전, 궁극기와 충돌 반경은 변경하지 않았습니다.
