# 원격돌격 킁킁·노바 임팩트 업데이트

## 변경 사항
- 킁킁 기본 공격 호박탄이 적중하면 주황빛 호박 섬광, 금빛 충격 링, 덩굴/호박 조각 임팩트가 발생합니다.
- 킁킁 궁극기 유도 호박 표창이 적중하면 기본 공격보다 크고 화려한 할로윈 전용 폭발 임팩트가 발생합니다.
- 노바 일반 공격 별 투사체의 적중 임팩트 지속시간을 늘려 진주빛 링과 별 조각이 더 또렷하게 보이도록 했습니다.
- 노바 크리스탈 모드 검격이 적중하면 보라·하늘색 수정 충격파와 프리즘 파편 임팩트가 발생합니다.
- 유저 매칭에서 상대가 쏜 킁킁/노바 공격을 맞았을 때도 피격자 화면에 같은 임팩트가 표시되도록 했습니다.
- 전투 수치, 재장전, 궁극기 충전량, 캐릭터 히트박스는 변경하지 않았습니다.
