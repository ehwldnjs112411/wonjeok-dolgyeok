# 원격돌격 · 좀비모드 버프 카드 & 볼트 모바일 자동 조준 업데이트

## 반영 내용
- 볼트 모바일 일반 공격을 공격 버튼을 누르는 즉시 가까운 살아 있는 적에게 자동 조준해 발사하도록 변경했습니다. 드래그 조준은 제거했습니다.
- 볼트 탄창을 3발로 고정하고, 재장전 간격은 2초로 유지하면서 연속 발사 간격을 짧게 조정했습니다.
- 볼트 기본 공격 사거리를 엘리 궁극기 범위의 정확히 1.4배로 설정했습니다.
- 좀비모드에서 화면 밖 좀비 방향 화살표, 맵 중앙 스폰을 유지했습니다.
- 5웨이브마다 아직 획득하지 않은 카드 중 2장을 제시하고 1장을 선택하도록 했습니다. 11종 카드의 효과와 중복 방지, 전부 획득한 뒤 카드 선택 종료를 적용했습니다.
- 10웨이브를 클리어할 때마다 다음 웨이브부터 좀비 공격력이 10%씩 증가합니다.
- 좀비모드 전용 음악을 지정한 트랙(uA6mBZRrMjA)으로 설정했습니다. 메뉴 음악 동작은 유지했습니다.

## 좀비모드 마지막 좀비에서 전투가 멈추는 현상 재수정
- 일반 전투의 `모든 적 사망 = 승리` 처리를 좀비모드에서는 적용하지 않도록 기본 피해 판정을 분리했습니다.
- 기존 복구 로직이 `updateGame()` 안에서만 실행되어 `game.ended` 상태에서는 실행되지 않던 구조를 수정했습니다.
- 애니메이션 프레임 루프에서 `game.ended` 분기보다 먼저 좀비 상태를 검사하도록 변경했습니다. 플레이어가 살아 있는데 종료 플래그가 잘못 켜져 있으면 즉시 해제하고 전투 입력/업데이트를 재개합니다.
- 살아 있는 좀비가 없으면 웨이브 클리어/휴식 단계로 한 번만 진입하고, 이미 휴식 중이거나 버프 카드 선택 중이면 중복 처리를 하지 않습니다.
- 현재 살아 있는 좀비를 단일 적 참조(`game.enemy`)에도 동기화해 조준/HUD 대상이 죽은 좀비를 계속 가리키지 않도록 했습니다.

## 2026-11-15 좀비모드 웨이브 정지 원인 수정
- 웨이브 클리어 후 버프 카드 처리 래퍼에서 존재하지 않는 `previousZombieWaveClear()`를 호출하던 변수명 오타를 수정했습니다. 정확한 참조는 `previousZombieWaveClearForCards()`입니다.
- 이 참조 오류는 마지막 좀비가 처치되어 웨이브 클리어 함수가 실행되는 순간 `ReferenceError`를 발생시켜 애니메이션/게임 업데이트 루프를 중단시켰습니다.
- 수정 후 Chromium 브라우저에서 1~5웨이브를 차례로 클리어하고 2~6웨이브가 생성되는 것을 확인했습니다. 5웨이브 버프 카드 표시 및 카드 선택 뒤 6웨이브 진입도 확인했습니다.
- 해당 브라우저 테스트 중 페이지 JavaScript 오류 0건을 확인했습니다.
- 테스트는 웨이브 클리어 경로를 자동으로 실행한 브라우저 테스트이며, 실제 Render 배포 및 iPhone Safari 실기기 플레이는 아직 별도 확인이 필요합니다.


## 2026-11-15 볼트 모바일 수동 조준 + 탭 오토에임 수정
- 이전 볼트 전용 `pointerdown` 즉시 자동 발사 처리를 제거했습니다. 이제 기본 공격 버튼은 공용 입력 제스처를 사용합니다.
- 공격 버튼을 바로 눌렀다 떼면 손가락 이동 없이 release 시점에 가장 가까운 생존 적을 자동 조준해 발사합니다.
- 공격 버튼을 누른 채 24px보다 멀리 드래그하면 드래그 방향이 조준 방향이 되고, 손을 떼면 그 방향으로 발사합니다. 짧은 터치 흔들림은 탭으로 처리합니다.
- 수동 조준 시에는 해당 방향의 번개 타격 범위 안에 있는 적을 선택하고, 적이 조준선에 없으면 사거리 끝 지점을 타격하도록 했습니다. 이전 코드처럼 수동 조준 방향이 다시 최근접 적 자동 조준으로 덮어써지지 않습니다.
- 볼트의 조준 미리보기 길이를 기본 공격 사거리(엘리 궁극기 범위의 1.4배)에 맞췄고, 일반 대전/좀비 모드 안내 문구를 탭/드래그 방식에 맞게 수정했습니다.
