# 원격돌격 — 천국 이벤트 업데이트

## 포함 파일
- `index.html` — 천국 이벤트, 천계 보스, 천사사탕 미션, 메르시 한정 전사 처리
- `server.js` — 기존 온라인 서버 유지
- `package.json` — 기존 Node.js 의존성 유지

## 천국 이벤트 변경 사항
- 메뉴의 이벤트 버튼을 `천국 이벤트`로 변경
- 천계 보스: 체력 500, 기존 할로윈 보스의 공격 패턴 유지
- 5초마다 80% 확률로 회복 구슬 생성 (플레이어가 먹으면 체력 10 회복)
- 10초마다 85% 확률로 천상 표창 생성 (먹으면 보스에게 유도 피해 25)
- 천계 보스 승리 1회마다 천사사탕 1개 지급
- 미션은 완료 즉시 자동 지급되지 않으며, 각 미션의 `받기` 버튼을 눌러 수령
  1. AI 매칭 5승: 천사사탕 6개
  2. 좀비모드 10웨이브 클리어: 천사사탕 5개
  3. 천계 보스 1회 클리어: 천사사탕 6개
  4. 탑 모드 15층 클리어: 천사사탕 5개
- 기존 계정의 탑 모드 15층 이상 기록도 미션 완료로 인정
- 천사사탕 30개를 모으면 메르시 영입 가능
- 메르시는 상점 구매 대상에서 제거하고 천국 이벤트 한정 전사로 변경
- 메르시 미니 천사는 체력 5를 유지하고 소환 후 5초 뒤 사라짐

## 배포
기존 Render 서비스에 이 ZIP의 파일을 풀어 GitHub 저장소의 동일 파일을 교체한 뒤 배포합니다. `server.js`와 `package.json`은 기존 버전을 유지했습니다.
