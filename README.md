# 원격돌격 · 볼트 조준 / 좀비맵 / 메뉴 음악 업데이트

## 이번 업데이트
- 볼트 모바일 일반 공격을 엘리 궁극기와 같은 누른 채 드래그하는 위치 지정 방식으로 변경
- 볼트 기본 공격 사거리를 직전 버전의 2배로 확대
- 볼트 궁극기 충전량과 누적 명중 횟수를 HUD에 표시
- 메뉴 음악만 지정된 YouTube 영상(AztRbo-sUQM)으로 변경하고 기존 켜기/끄기 및 전투 후 복귀·재개 기능 유지
- 좀비모드 전장 월드 크기를 기존의 2배로 확대하고, 기존 화면 크기는 유지한 채 카메라가 플레이어를 따라가도록 변경
- 좀비 웨이브 클리어 시 현재 체력과 최대 체력을 각각 10씩 증가

## 배포 방법
1. ZIP의 압축을 풉니다.
2. GitHub 저장소 최상위 폴더에서 `index.html`, `server.js`, `package.json`, `README.md`를 교체합니다.
3. 커밋하고 푸시합니다. Render는 기존 설정대로 배포됩니다.

이번 변경은 게임 화면과 클라이언트 로직만 수정했으므로 `server.js`와 `package.json`은 이전 볼트 배포본을 그대로 포함했습니다.
