# 원격돌격 · 좀비모드 & 볼트 업데이트

## 이번 업데이트
- 우편함에서 기간이 지난 할로윈 선물 항목을 제거했습니다. 기존 영구 환영 선물은 유지됩니다.
- 기존 AI 매칭과 탑 모드는 유지하고, AI 모드 선택 화면에 무한 웨이브 방식의 `좀비모드`를 추가했습니다.
- 일반좀비, 강철좀비, 원거리좀비와 10웨이브마다 등장하는 좀비보스를 추가했습니다.
- 웨이브 종료 시 체력 회복과 휴식 시간을 제공하며, 웨이브 보상은 패배 시 누적 금액을 한 번에 지급합니다. 좀비모드에서는 트로피가 차감되지 않습니다.
- 좀비모드 최고 웨이브 기록을 표시합니다.
- 신규 전사 `볼트`를 추가했습니다. 체력 90, 상점 가격 1,500 원코인입니다. 지정 위치에 번개를 떨어뜨리는 일반 공격과 명중 횟수에 따라 강화되는 360도 전기파 궁극기를 사용합니다.
- 서버의 전사 검증 목록과 계정 해금 데이터에 볼트를 추가했습니다. 기존 계정은 DB 마이그레이션으로 기존 보유 정보를 유지하며 볼트 해금값을 추가합니다.

## GitHub 배포 방법
1. ZIP 파일을 다운로드한 뒤 압축을 풉니다.
2. 압축 안의 `index.html`, `server.js`, `package.json`, `README.md` 네 파일을 GitHub 저장소 최상위 폴더에 업로드하고 기존 파일을 교체합니다.
3. 변경 사항을 커밋/푸시합니다. Render 자동 배포가 켜져 있으면 새 버전이 배포됩니다.
4. Render의 환경 변수 `DATABASE_URL`, `JWT_SECRET`이 기존과 같이 설정되어 있는지 확인합니다.

## 배포 파일 구성
- `index.html`: 전체 게임 화면과 게임 로직
- `server.js`: 정적 파일 제공, 계정 API, Socket.IO 매칭 및 전투 메시지 중계
- `package.json`: 기존 런타임 의존성을 유지한 업데이트 버전 정보
- `README.md`: 이번 버전 적용 내용과 배포 안내

## 확인 사항
- `server.js` Node.js 문법 검사
- `package.json` JSON 파싱 검사
- HTML 인라인 JavaScript 블록 검사
- ZIP 파일 무결성 검사

실제 브라우저 플레이와 Render 온라인 2인 대전은 배포 후 별도로 테스트해야 합니다.
