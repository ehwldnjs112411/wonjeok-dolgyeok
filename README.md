# 원격돌격 업데이트

## 적용 내용
- 비트 체력 85 → 75로 하향. 궁극기 1초 준비 범위가 비트 캐릭터를 따라 이동하며, 온라인 상대 화면에도 동일하게 표시됩니다.
- 신규 일반 전사 프마 추가: 체력 95, 재장전 2초, 중거리 성광 폭격(8 피해), 8회 적중 궁극기.
- 프마 궁극기는 엘리보다 넓은 반경 125의 블랙홀을 6초간 유지하고, 적을 중심으로 끌어당기며 초당 1 피해를 줍니다. 온라인 매칭 이벤트도 추가했습니다.
- 뿌지직 기본 공격에 탄환별 20% 확률로 추가 5 피해 치명타를 적용했습니다.
- 프마는 상점에서 원코인 1,500개로 구매할 수 있습니다.
