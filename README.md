# 원격돌격 · 볼트 및 좀비모드 버그 수정

## 수정한 사항
- 볼트의 번개 낙하 처리를 좀비모드에만 한정하지 않고 모든 전투 모드에서 갱신하도록 수정했습니다. 조준 지점에 0.5초 예고 후 번개가 한 번 내려치며 범위 내 적에게 피해 6을 줍니다.
- 모바일 볼트 일반 공격 버튼을 누른 채 드래그할 때 사거리 원과 지정 낙하지점 표시가 나타나고, 손을 떼면 그 위치에 번개가 떨어지도록 조준 처리를 수정했습니다.
- 좀비모드의 좀비 AI가 당기기 상태를 처리하도록 수정했습니다. 스피디 궁극기와 마그넷 궁극기에 맞은 좀비가 시전자 쪽으로 끌려옵니다.
- 좀비모드에서 구미 궁극기의 매혹 상태를 일반 기절과 구분해 처리하도록 수정했습니다. 매혹된 좀비는 1초 동안 구미 쪽으로 이동합니다.

## GitHub 배포
1. ZIP을 압축 해제합니다.
2. `index.html`, `server.js`, `package.json`, `README.md`를 저장소 최상위 폴더에 업로드합니다.
3. 현재 수정에서 실제 게임 로직이 변경된 파일은 `index.html`입니다. `server.js`와 `package.json`은 이전 볼트 배포본을 그대로 포함했습니다.
4. GitHub에서 커밋/푸시하면 Render 자동 배포 설정에 따라 반영됩니다.

## 확인
- HTML 인라인 JavaScript 문법 검사 통과
- `server.js` Node.js 문법 검사 통과
- `package.json` JSON 검사 통과
- ZIP 무결성 검사 통과
- 실제 전투 플레이 테스트는 배포 후 확인이 필요합니다.
